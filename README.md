# Brahim Walid - Academic Portfolio

This is the personal portfolio website for Brahim Walid, PhD Candidate at Hosei University, Japan, specializing in context-aware vital signs monitoring using FMCW radar.

## Website Sections

- **Home**: Introduction and overview
- **About**: Personal background and education
- **Research**: Research projects and focus areas
- **Publications**: Academic publications including journal papers, conference papers, and posters
- **Skills**: Technical and soft skills
- **Awards**: Academic honors and achievements
- **Blog**: Articles and insights on research topics
- **Contact**: Contact information and form

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons
- Responsive Design

## Deployment

This website is deployed using GitHub Pages.

## Maintenance

To update the website:
1. Clone the repository
2. Make changes to the relevant files
3. Commit and push changes to GitHub
4. GitHub Pages will automatically update the live site
